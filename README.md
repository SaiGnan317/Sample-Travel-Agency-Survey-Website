A travel survey website built with HTML and CSS that collects traveler preferences and presents the data through analysis and results pages. It includes personalized travel information, survey integration, navigation, feature sections, and visual representations of the collected results.

# Travel Survey Website

A simple HTML and CSS-based travel survey website designed to collect and present information about travelers' preferences, habits, budgets, transportation choices, and travel patterns.

### Features

* Home page with travel information
* Google Forms survey integration
* About section explaining the purpose of the survey
* Analysis page for collected survey data
* Results page with visual representations
* Navigation between different pages
* Travel recommendations based on collected preferences

### Technologies Used

* HTML5
* CSS3
* Google Forms
* Images and visual content

### Purpose

The project demonstrates how survey data can be collected and presented through a simple web interface to understand travel preferences and identify common travel trends.
